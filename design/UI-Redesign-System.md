# EasyWork 界面重新设计方案 · UI Design System

> **版本**：v1.0 ｜ **日期**：2026-08-07 ｜ **设计师**：UI Designer（像素君）
> **范围**：整体视觉风格、核心页面布局、主要交互流程、组件规范、响应式与无障碍
> **技术栈对齐**：React 19 + Vite + Tailwind v4 + shadcn/ui（new-york）+ TanStack Router + Tauri 桌面端 + 移动端

---

## 0. 设计背景与目标

### 现状诊断
当前 EasyWork 基于 shadcn/ui 的 **zinc 中性主题**，功能完整但存在以下体验问题：
1. **缺乏品牌识别**：全局为无色彩倾向的灰阶，无法与"EasyWork"的产品个性建立联系。
2. **桌面导航效率低**：左侧为 56px 纯图标栏，必须悬停才显示文字，频繁使用时认知成本高、可发现性差。
3. **视觉层次偏弱**：所有模块共用同一套灰底卡片，重要信息（如待办、金额、未读）缺少强调锚点。
4. **多栏模块移动端降级不明确**：邮箱/笔记的 3 栏/2 栏结构在窄屏如何切换缺少统一规范。

### 设计目标
- **美观性**：建立有记忆点的"安静而精致"的视觉语言（irisfont 品牌色 + 暖灰中性 + 衬线点缀）。
- **易用性**：桌面端可标注侧边栏、统一新建入口、全局命令面板；移动端保持单手可达。
- **一致性**：一套设计令牌同时驱动亮/暗主题与桌面/移动端，组件跨模块复用率 > 95%。

### 目标用户画像
- **主角**：自由职业者 / 小团队负责人，把"任务、邮件、笔记、记账"放在一个工作台里。
- **使用情境**：每天开站后先看仪表盘聚焦今日；过程中在任务看板推进、写笔记、回邮件、随手记账。
- **核心诉求**：少切换、少噪音、信息一眼可扫、关键操作两步内可达。

## 1. 设计理念（Design Principles）

| 原则 | 含义 | 落地 |
|------|------|------|
| 安静优先 | 界面退后，内容在前 | 中性底色占 60%，品牌色仅用于 CTA/激活态/强调（≤10%） |
| 一眼扫读 | 重要信息自带锚点 | 优先级圆点、未读粗体、金额 Tabular 数字、状态徽章 |
| 两步可达 | 高频操作零跳转 | 全局 ⌘K 命令面板 + 上下文"新建"按钮 + 详情抽屉 |
| 平滑过渡 | 状态变化有反馈 | 面板/抽屉用指数缓动（ease-out-quart），尊重 reduced-motion |
| 一致可预期 | 同物同形 | 所有"新建"用同一主按钮；所有列表行交互一致 |

## 2. 视觉风格（Visual Foundations）

### 2.1 色彩系统（OKLCH，感知均匀）

> 采用 OKLCH 而非 HSL：等亮度步进在视觉上一致；中性色带极微弱品牌色相（chroma 0.008–0.014），避免"死灰"。

**品牌主色 — Iris（鸢尾靛）**，色相 264，沉静而具辨识度（避开青+深、紫蓝渐变、霓虹等 AI 套路色）：

| Token | OKLCH | 用途 |
|-------|-------|------|
| `--brand-50` | `oklch(96% 0.02 264)` | 选中/悬停底色 |
| `--brand-100` | `oklch(92% 0.04 264)` | 软强调背景 |
| `--brand-300` | `oklch(74% 0.11 264)` | 图标/描边 |
| `--brand-500` | `oklch(56% 0.17 264)` | **主色 / 主按钮** |
| `--brand-600` | `oklch(49% 0.16 264)` | 主色 hover |
| `--brand-700` | `oklch(42% 0.14 264)` | 主色 active |

**暖调中性（Neutral）**，色相 70，极弱彩度，比 zinc 更"有人味"：

| Token | OKLCH（亮） | OKLCH（暗） | 用途 |
|-------|-----------|-----------|------|
| `--bg` | `oklch(98.5% 0.004 70)` | `oklch(17% 0.008 264)` | 页面底色 |
| `--surface` | `oklch(100% 0.002 70)` | `oklch(21% 0.01 264)` | 卡片/面板 |
| `--surface-raised` | `oklch(100% 0.004 70)` | `oklch(26% 0.012 264)` | 弹层/抽屉 |
| `--surface-sunken` | `oklch(96.5% 0.006 70)` | `oklch(14% 0.006 264)` | 输入框/次级区 |
| `--border` | `oklch(92% 0.008 70)` | `oklch(30% 0.012 264)` | 分割线 |
| `--text` | `oklch(24% 0.01 70)` | `oklch(95% 0.004 70)` | 正文 |
| `--text-muted` | `oklch(52% 0.014 70)` | `oklch(72% 0.012 264)` | 次要文字（已验证 ≥4.5:1） |

**语义色（Semantic）**：

| 角色 | OKLCH | 用途 |
|------|-------|------|
| `--success` | `oklch(64% 0.15 150)` | 完成/收入/通过 |
| `--warning` | `oklch(72% 0.15 55)` | 临近截止/超预算 |
| `--danger` | `oklch(58% 0.21 25)` | 删除/错误/失败 |
| `--info` | `= --brand-500` | 提示/进行中 |
| `--accent`（点缀金） | `oklch(82% 0.12 90)` | 收藏星标、成就、正向微反馈（≤10% 面积） |

**对比度承诺（WCAG AA）**：正文 `--text` 对 `--bg` ≥ 7:1；`--text-muted` 对 `--bg` ≥ 4.5:1；图标/控件 ≥ 3:1；主按钮文字白/深均达 4.5:1。颜色**从不作为唯一信息载体**（状态必配图标+文字）。

### 2.2 排版系统（Typography）

| 角色 | 字体 | 用法 | 字重 |
|------|------|------|------|
| 展示/品牌 | **Fraunces**（衬线，光学尺寸） | Logo、页面大标题、空状态标题 | 400–600 |
| 界面/正文 | **Plus Jakarta Sans** | 全部 UI、正文、按钮 | 400–700 |
| 数据/等宽 | **JetBrains Mono** | 金额、日期、代码、编号 | 500（tabular-nums） |

**字号阶梯（固定 rem，数据密集界面不用流式字号）**：

| Token | 值 | 行高 | 用途 |
|-------|----|------|------|
| `--fs-xs` | 12px | 1.5 | 标签、脚注、元信息 |
| `--fs-sm` | 14px | 1.5 | 次要 UI、列表元信息 |
| `--fs-base` | 16px | 1.6 | 正文（移动端最低 16px） |
| `--fs-lg` | 18px | 1.5 | 卡片标题、副标题 |
| `--fs-xl` | 22px | 1.35 | 区块标题 |
| `--fs-2xl` | 28px | 1.25 | 页面标题 |
| `--fs-3xl` | 36px | 1.15 | 仪表盘大数字/空状态 |

> 垂直节奏：以 16px×1.6=25.6px 为基准单位，纵向间距取 8/16/24/32 的倍数，建立潜意识和谐。

### 2.3 间距 / 圆角 / 阴影 / 动效

- **间距（4px 基）**：`--sp-1=4 --sp-2=8 --sp-3=12 --sp-4=16 --sp-6=24 --sp-8=32 --sp-12=48 --sp-16=64`。用间距变化制造节奏，而非万物等距。
- **圆角**：控件 10px、卡片 14px、大容器 20px、气泡/头像全圆。比原 8px 更柔和、更现代。
- **阴影（仅在亮色用，暗色靠表面提亮做层级）**：
  - `--shadow-xs` `0 1px 2px oklch(24% 0.01 70 / 0.06)`
  - `--shadow-sm` `0 1px 3px …/0.08, 0 1px 2px …/0.06`
  - `--shadow-md` `0 4px 12px …/0.10`
  - `--shadow-lg` `0 12px 32px …/0.14`（抽屉/弹层）
- **动效**：过渡 `160ms` 基础态、`280ms` 面板、`ease-out-quart` 用于位移；**不**动画化 layout 属性（width/height/top），用 transform/opacity；`@media (prefers-reduced-motion: reduce)` 全部降级为瞬时。

## 3. 应用外壳与导航（App Shell & Navigation）

### 3.1 桌面端布局
```
┌──────┬───────────────────────────────────────────────┐
│      │  顶栏: [全局搜索 ⌘K]   页标题/面包屑    [+新建][🔔][🌗][头像] │
│ 侧   ├───────────────────────────────────────────────┤
│ 边   │                                                 │
│ 栏   │              主内容区（按模块切换）              │
│(可   │                                                 │
│ 折   │                                                 │
│ 叠)  │                                                 │
└──────┴───────────────────────────────────────────────┘
```
- **侧边栏（可折叠）**：默认展开 240px，含分组「工作区：仪表盘/任务/邮箱/笔记/记账」与底部「设置/账户」。折叠为 72px 图标栏（带 tooltip）。激活态 = 品牌浅底 + 左侧 3px 品牌竖条 + 品牌色图标 + 中粗体文字。相比原 56px 纯图标栏，可发现性显著提升。
- **顶栏**：左侧全局搜索（⌘K 命令面板触发器），中部当前页标题/面包屑，右侧上下文「+ 新建」（随页面变化）、通知、主题切换、头像。

### 3.2 移动端布局
```
┌─────────────────────┐
│ 顶栏: [☰/搜索]        [🌗][头像] │
├─────────────────────┤
│                      │
│   主内容（单栏）      │
│                      │
├─────────────────────┤
│  底部 Tab: 仪表·任务· │
│  邮箱·笔记·记账        │
└─────────────────────┘
```
- 底部 Tab Bar 保留 5 个主模块（≥44px 触控区、含 safe-area-inset），设置/账户收进顶栏头像菜单。
- 多栏模块（邮箱/笔记）在移动端为「列表 ↔ 详情」单栏切换，带返回箭头，不隐藏任何功能。

## 4. 核心页面布局（Core Page Layouts）

### 4.1 仪表盘 `/dashboard`
- 顶部：问候语 + 日期；右侧快捷「+ 新建」。
- KPI 行：4 张统计卡（今日待办 / 未读邮件 / 笔记数 / 本月支出），大数字用 `--fs-3xl` + 趋势小标。
- 「今日聚焦」任务清单（优先级圆点 + 时间 + 一键完成）。
- 「近期记账」迷你面积图（Recharts）+ 「快速记账」入口。
- 空状态：首次使用展示引导卡，而非空白。

### 4.2 任务 `/tasks`
- 工具条：视图切换（**看板 / 列表 / 日历**）+ 筛选（优先级/负责人/标签）+ 「+ 新建任务」。
- **看板**：列 = 待办 / 进行中 / 待审核 / 完成；卡片含优先级圆点、标题、标签、截止日、负责人头像；支持拖拽（@dnd-kit）。
- **列表**：可排序列，行内完成勾选。
- **日历**：月视图，任务以彩色点表示，点击落点打开详情抽屉。
- 详情：右侧抽屉（Drawer）展示完整字段与子任务，编辑就地展开。

### 4.3 邮箱 `/mail`
- 桌面三栏：① 账户/文件夹树 ② 邮件列表 ③ 阅读器；阅读器内「回复/转发」唤起撰写抽屉。
- 移动：列表 ↔ 阅读器单栏切换；撰写为全屏抽屉。
- 未读：发件人加粗 + 品牌色圆点；选中行品牌浅底。

### 4.4 笔记 `/notes`
- 桌面两栏：① 笔记列表/笔记本侧栏 ② Tiptap 编辑器（顶部格式工具条）。
- 移动：列表 ↔ 编辑器单栏；保存状态「已保存」即时提示。
- 空状态：模板卡片（会议记录 / 灵感 / 待办）一键新建。

### 4.5 记账 `/finance`
- 顶部 Tab：总览 / 账户 / 交易 / 预算 / 报表。
- **总览**：总资产/本月收支大卡 + 分类环形图（支出结构）+ 趋势折线。
- **交易**：表格（日期、账户、分类、金额用 Tabular Mono，收入绿/支出中性）+ 行内筛选。
- **预算**：各分类进度条（剩余=品牌色，超支=危险色）。
- **报表**：周期对比柱状 + 导出。

### 4.6 设置 `/settings`
- 左侧分区（账户 / 外观 / 通知 / 数据 / 关于）+ 右侧面板。
- **外观**：主题（亮/暗/跟随系统）、强调色（Iris / 后续可扩展）、密度（舒适/紧凑）。

## 5. 主要交互流程（Key Flows）

1. **全局命令面板（⌘K / Ctrl+K）**：搜索页面、任务、笔记、联系人；执行新建/切换主题等动作。渐进式披露，键盘全可达。
2. **新建流程**：上下文「+ 新建」→ 抽屉/弹层表单（统一字段规范）→ 保存后原地刷新列表 + Toast 成功提示。
3. **主题切换**：亮/暗/系统三态，持久化到 localStorage，无闪烁（初始内联脚本读偏好）。
4. **任务详情**：列表/看板卡片 → 右侧抽屉，支持就地编辑与子任务勾选。
5. **空状态引导**：首次/无数据场景给出下一步动作，降低弃用率。

## 6. 组件规范（Component Specs）

| 组件 | 规范要点 |
|------|----------|
| **Button** | 变体：primary（品牌实心）/ secondary（描边）/ ghost（纯文字）/ danger；尺寸 sm(32)/md(40)/lg(48)；图标按钮 40×40；禁用态降透明度+禁指针；focus-visible 2px 品牌环+2px 偏移 |
| **Input / Textarea** | 高 40px、圆角 10、sunken 底；focus 边框品牌色 + 柔光环；placeholder 用 `--text-muted`（已达标） |
| **Select / Dropdown** | 触发器同 Input；菜单 surface-raised + shadow-lg；选项 hover 品牌浅底 |
| **Checkbox / Radio** | 品牌色填充 + 白勾；≥20px 触控 |
| **Badge / Tag** | 圆角全/8；状态色用浅底+深字（非纯色块）；优先级圆点 8px |
| **Card** | 圆角 14、surface 底、shadow-sm；hover 微抬升（仅亮色、可关） |
| **Dialog / Drawer** | 弹层 shadow-lg + 遮罩；抽屉从右滑入（transform）；ESC 关闭、focus trap、滚动锁 |
| **Tabs** | 下划线/胶囊二式；激活品牌色 + 指示条位移动画 |
| **Tooltip** | 延迟 200ms、暗底浅字、不遮挡触发源 |
| **Avatar** | 圆；无图显示首字（品牌浅底+品牌字）；状态点（在线绿） |
| **Toast** | 右下出现、自动消失 4s、含图标+文案+可选操作 |
| **Progress** | 高 8px、圆角全；正常品牌色、超阈危险色 |
| **Table** | 行高 52px、斑马可选；数字 Tabular Mono 右对齐；排序箭头 |
| **Skeleton** | 品牌浅底 shimmer（reduced-motion 下静态） |

**状态全覆盖**：每个组件具备 default / hover / active / focus / disabled / loading / error / empty 规范。

## 7. 响应式策略（Responsive）

| 断点 | 宽度 | 策略 |
|------|------|------|
| 手机 | <768px | 单栏；底部 Tab；多栏模块降级为列表↔详情；触控 ≥44px |
| 平板 | 768–1023px | 侧边栏折叠为图标栏；邮箱/笔记保留双栏（若空间够） |
| 桌面 | 1024–1279px | 展开侧边栏；多栏完整 |
| 大屏 | ≥1280px | 容器最大宽 1280，居中；留白更舒展 |

- 用 **容器查询（@container）** 让卡片在窄容器内自动换行，而非整页断点。
- **绝不**在移动端隐藏关键功能；仅重排。

---

## 8. 无障碍（Accessibility · WCAG AA）

- **对比度**：正文 ≥4.5:1、大字 ≥3:1、控件 ≥3:1（已按 2.1 取值验证）。
- **键盘**：全功能可 Tab 操作；命令面板/抽屉 focus trap；可见 focus 环。
- **屏幕阅读器**：语义标签 + ARIA（nav/region/dialog/aria-current）、图标按钮带 `aria-label`。
- **触控**：交互元素 ≥44×44px。
- **动效敏感**：尊重 `prefers-reduced-motion`。
- **缩放**：使用 rem；支持浏览器 200% 缩放不破版。
- **不止于色**：状态/优先级均配图标或文字，色盲友好。

## 9. 设计令牌落地（给开发的对照）

亮/暗主题仅切换**语义层**，原色（primitive）保持不变，便于维护：

```css
:root{
  --brand-500: oklch(56% 0.17 264);
  --bg: oklch(98.5% 0.004 70);
  --surface: oklch(100% 0.002 70);
  --text: oklch(24% 0.01 70);
  --text-muted: oklch(52% 0.014 70);
  --border: oklch(92% 0.008 70);
  --radius: 14px; --radius-sm: 10px;
}
[data-theme="dark"]{
  --bg: oklch(17% 0.008 264);
  --surface: oklch(21% 0.01 264);
  --text: oklch(95% 0.004 70);
  --text-muted: oklch(72% 0.012 264);
  --border: oklch(30% 0.012 264);
}
```
