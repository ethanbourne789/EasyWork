# EasyWork 界面重新设计 · 交付概览

## 做了什么
对 EasyWork（Tauri 桌面端全能生产力工作台）进行了一次完整的 UI 重新设计，产出了 **设计系统文档** 与 **可交互 HTML 原型** 两份交付物。

## 交付物
1. **`design/UI-Redesign-System.md`** — 完整设计系统方案
   - 现状诊断 + 设计目标 + 用户画像
   - 视觉风格：OKLCH 色彩系统（Iris 鸢尾靛主色 + 暖调中性 + 语义色）、排版（Fraunces / Plus Jakarta Sans / JetBrains Mono）、间距/圆角/阴影/动效
   - 应用外壳与导航（可折叠侧边栏、顶栏、移动端底部 Tab）
   - 6 个核心页面布局（仪表盘/任务/邮箱/笔记/记账/设置）
   - 主要交互流程（⌘K 命令面板、新建、主题、任务详情、空状态）
   - 组件规范、响应式断点、WCAG AA 无障碍、令牌落地示例
2. **`design/easywork-ui-prototype.html`** — 单文件可交互原型
   - 顶部预览栏可切换 **桌面 / 平板 / 手机**，一键 **亮/暗主题**
   - 点击左侧导航或底部 Tab 切换 仪表盘 / 任务看板 / 邮箱 / 笔记 / 记账
   - 真实渲染设计令牌、看板拖拽卡片、邮箱三栏、笔记双栏、记账图表与预算条
   - 移动端自动降级为多栏→单栏、底部 Tab、安全区适配

## 设计要点
- **品牌识别**：单一 Iris 鸢尾靛强调色（避开青+深、紫蓝渐变、霓虹等 AI 套路色），强调色仅占 ≤10% 视觉权重。
- **易用性**：桌面侧边栏改为带文字的可折叠标注栏（替代原 56px 悬停图标栏）；全局 ⌘K 命令面板；高频操作两步可达。
- **一致性**：同一套令牌驱动亮/暗与桌面/移动端；所有状态/优先级均配图标+文字，不依赖颜色。
- **层级约定**：
  - 所有模态/抽屉统一使用 shadcn/ui `Dialog` / `Drawer` / `Sheet`（z-index 由组件内部管理，通常为 `z-50`）。
  - 全局 Toast 使用 `z-[9999]`，位于最顶层。
  - 禁止业务组件手写 `fixed inset-0 z-40/z-50` 遮罩；已有手写遮罩逐步迁移到标准组件。
